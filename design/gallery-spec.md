# Capture gallery design note

## Purpose

Let readers inspect two genuine captures of the public guide and see which published revision and viewport each one represents.

## Layout

- A short dark header identifies the guide and states the gallery's purpose.
- Two semantic figure cards place the desktop and emulated portrait captures side by side on wide screens and in one column on narrow screens.
- Captions show the viewport, source revision, capture-time availability, and image digest.
- A compact baseline note states the focused runtime findings and their limits.

## Accessibility and assets

Use native headings, articles, figures, captions, links, and definition lists. Every image has descriptive alternative text. Focus indicators remain visible. All styling is local; no external fonts, scripts, tracking, game artwork, or map tiles are included. The narrow layout begins below 720 CSS pixels.

## Design-tool availability

The dedicated design-tool connection was absent from the available tool inventory during this task. The page therefore uses the documented direct static-site route and this written handoff as its design record.
